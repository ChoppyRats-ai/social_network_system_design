# Database schema for social network

## Описание задания

В данной директории находится схема базы данных для социальной сети, похожей на ВКонтакте.

Необходимо спроектировать структуру базы данных для хранения и обработки следующих сущностей:

- анкеты пользователей;
- посты;
- личные сообщения и чаты;
- отношения между пользователями;
- медиафайлы.

Схема проектируется в формате ER-модели.

## Предметная область

Проектируемая социальная сеть должна поддерживать:

### 1. Анкеты людей
Для пользователей необходимо хранить:
- имя;
- описание профиля;
- фото;
- город;
- интересы.

### 2. Посты
Для постов необходимо предусмотреть:
- текстовое описание;
- медиа;
- хэштеги;
- лайки;
- просмотры;
- комментарии.

### 3. Личные сообщения и чаты
Система сообщений должна поддерживать:
- личные диалоги;
- групповые чаты;
- текст сообщений;
- статус прочитанности сообщений.

### 4. Отношения между пользователями
Необходимо хранить разные типы отношений:
- друзья;
- подписчики;
- любовные отношения.

### 5. Медиа
Отдельно должны быть продуманы сущности для хранения:
- фото;
- аудио;
- видео.
